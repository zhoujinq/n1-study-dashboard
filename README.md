# 日语 N1 备考学习看板 · 静态预览

这是从个人本地学习看板抽出的 GitHub Pages 版本，保留原页面布局、学习计划、当前进度摘要和首屏练习样式。

## 发布范围

| 需求 | 本版本实现 |
| --- | --- |
| 本地 HTML 公开为网页源代码 | 根目录 `index.html`，复用原有 CSS 与 JavaScript |
| 在线打开与本地看板一致 | 保留当前考期首屏题目、当前五词、学习统计和 12 周计划 |
| 不上传 PDF、MP3 和大型资源 | 仅发布 HTML、CSS、JS、JSON、Markdown；媒体链接显示为“本地资源” |
| 静态托管可运行 | 用 `static-api.js` 替代本地 Python 接口，无需服务器端运行时 |
| 不改动原本地系统 | 本目录是独立发布副本；在线修改不会写回本地 `progress.json` |

## 在线版边界

- “保存本日进度”写入当前浏览器的 `localStorage`，可用“导出进度”备份；换浏览器或清除网站数据后不会自动恢复。
- 词汇区保留当前五词的静态预览，不含单词或例句音频，不保存新的词汇练习结果。
- 真题区保留当前考期的首屏题目；其他题目位置保留，但正文不公开。不含 PDF、MP3、完整 Anki 牌组和真题资源库。
- 完整功能仍在原来的本地学习系统中使用。

## 本地预览

在本目录启动任意静态 HTTP 服务，例如：

```powershell
python -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。不要通过 `file://` 双击验收，因为浏览器会限制 JSON 请求。

## 文件说明

- `index.html`：看板入口。
- `quiz.css`、`papers.css`、`preview.css`：原样式及静态资源提示样式。
- `quiz.js`、`papers.js`：原交互代码。
- `static-data.js`：经裁剪的首屏文字快照；已去除音频字段和绝大多数题目正文。
- `static-api.js`：静态数据响应与浏览器进度保存。
- `plan.json`、`progress.json`：学习计划与进度摘要。
- `日语N1备考计划_2026-12-06.md`：文字版完整计划。

